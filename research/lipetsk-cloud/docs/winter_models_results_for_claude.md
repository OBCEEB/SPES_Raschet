## 0. Итог одной строкой

Гипотеза приказа («log(Kt) занижает зимний Kt → Gadj < Gcrit → Qadj ≈ 0 в XI–I») **опровергнута оркулом**. Истинный суточный Kt, прогнанный через тот же профиль Gref и тот же ISO 9806, всё равно обнуляет **87.2 %** зимних часов и возвращает только **28.2 %** зимнего Qobs. Узкое место — внутридневная размазка суточной энергии по ясному ходу Hottel/СП, не функциональная форма log vs квантиль vs XGB.

Ни одна из поставленных моделей не решает зиму. Baseline log оставляем.

## 1. Что проверяли (гипотеза приказа)

Из `winter_models_complete.md` / таблицы §14.2:

| Месяц | Qobs в тексте приказа | Qadj log | Qadj/Qobs |
| --- | ---: | ---: | ---: |
| XI | «34» | «0» | 0.01 |
| XII | «24» | «1» | 0.02 |
| I | «56» | «11» | 0.20 |

Приказ назвал эти числа **кВт·ч/м²·мес**. В §14.2 те же 34 / 24 / 56 стоят в колонке **МДж/м²·мес** (годовой 416 кВт·ч = композит / 3.6). Перевод:

| Мес | Qobs МДж | Qobs кВт·ч | Qadj log МДж | log/obs |
| --- | ---: | ---: | ---: | ---: |
| XI | 34.00 | **9.4** | 0.44 | 0.013 |
| XII | 24.19 | **6.7** | 0.55 | 0.023 |
| I | 55.87 | **15.5** | 11.00 | 0.197 |

«24–56 кВт·ч/м² в месяц» в формулировке проблемы — путаница единиц (взяты МДж, названы кВт·ч). Обнуление Qadj в XI–XII от этого **не меняется**. Ниже везде МДж, кроме явно помеченных кВт·ч.

Цепочка, которую приказ считает виновной:

1. log(Kt) обучен на композите / year-wise → зимний Kt слишком низкий  
2. низкий Kt → низкий Gadj,h = Gref,h · Kt̂ / Kref_d  
3. G < Gcrit ≈ 210 Вт/м² почти весь световой день  
4. код обнуляет Q → месячный Qadj ≈ 0  

Три предложенные причины: мало зимы в train; log → −∞ при Kt→0; нет AR(1) на прояснениях.

Gcrit в метриках: η=0 при ΔT=40 K, Kτα=1:

```
Gcrit = (3.5×40 + 0.015×40²) / (0.78×1) = 164/0.78 ≈ 210.3 Вт/м²
```

В ISO-цикле Kτα считается по углу (не всегда 1), поэтому фактический порог слота чуть другой. Доля «Q=0» — по `qdot≤0` после полного IAM.

Параметры коллектора (те же, что пайплайн): η0=0.78, a1=3.5, a2=0.015, b0=0.1, ΔT=40 K, юг, β=φ, ρg=0.2. Это типичный остеклённый, не именной продукт.

## 4. Главный результат: оркул `oracle_obs_Kt`

Если подставить **наблюдаемый** суточный Kt в ту же цепочку Gref → Эрбс → ISO:

| | Все 972 | Зима XI–III n=350 | Лето V–IX n=445 | Плечо IV+X n=177 |
| --- | ---: | ---: | ---: | ---: |
| RMSE Kt | 0 | 0 | 0 | 0 |
| RMSE H, МДж/м²·сут | 0 | 0 | 0 | 0 |
| RMSE Q, МДж/м²·сут | 1.7948 | **2.1119** | 1.3466 | 2.0764 |
| MAE Q | 1.3174 | 1.4393 | 1.1292 | 1.5498 |
| MBE Q | −0.6254 | **−1.4393** | +0.2545 | −1.2283 |
| R² Q | 0.7132 | 0.3160 | 0.7849 | 0.5796 |
| доля часов Q=0 | 0.5904 | **0.8715** | — | — |

Зимний Qobs на 350 сутках: **701.53 МДж/м²** (сумма суточных). Оркул даёт **197.78** → **Q̂/Qobs = 0.2819**.

**Следствие.** Любая суточная регрессия Kt, какой бы точной она ни была, не может вернуть зимний Qadj, пока внутри дня энергия кладётся на ясный ход Hottel/СП. Зимой этот ход почти нигде не пересекает Gcrit. Пиранометр ловит короткие прояснения — пики, которых нет в Gref.

Поэтому сравнивать семь моделей по RMSE Kt зимой **недостаточно**. Приказ требовал RMSE Q и долю G≤Gcrit — они это и показали.

Лето оркула тоже не идеально (R² Q = 0.79): даже истинный суточный Kt + профиль Gref ≠ наблюдаемый внутридневной ход.

## 10. Как это стыкуется с формулировками приказа

> «Модель предсказывает зимнюю полезную теплоту в 5–100 раз меньше фактической.»

Для log: XI ×77, XII ×44, I ×5. Да, для log. Квантиль: XI ×17, XII ×19, I ×5. Порядок тот же. Оркул по сумме зимы XI–III: ×3.5 (701.53/197.78). Месяцы XI–XII оркула в этом файле отдельно не размазаны; потолок метода уже виден на сезоне.

> «При Kt → 0 логарифм → −∞, модель может давать пессимистичные предсказания.»

Зимний MBE Kt у log = −0.0058. Среднее не пессимистично. Пессимизм появляется **после** η(G) на гладком профиле.

> «Мало зимних данных, переоптимизация на лето.»

Зима n=350 из 972 (**36 %**). Не мало. Ансамбль, обученный отдельно на зиме, ещё сильнее убивает зимний Q (Q̂/Qobs = 0.25).

> «Без AR(1) не улавливает кратковременные прояснения.»

Суточный AR(1) этих прояснений всё равно не даст: они внутри дня. Нужен часовой kt или другой профиль. Часовой AR(1) с лагом Q — nowcast, в Qadj не идёт (уже зафиксировано в пайплайне).

> «Убрать log(Kref) или месяцы из-за мультиколлинеарности.»

`ols_no_kref` улучшает Kt (зима RMSE 0.071 vs 0.086) и RMSE Q (2.13 vs 2.34) относительно log, **не** долю Gcrit (0.862 vs 0.877) и не XI–XII (квантиль без Kref всё равно 6 % ноября).

> «Hurdle физически осмыслен — сначала P(коллектор работает).»

Hurdle здесь — логит на **суточном** Qobs>0.05 × OLS Kt. Это не P(G>Gcrit) на часе. Зимний Q̂/Qobs = 0.29, доля Q=0 = 0.868. Не называть моделью коллектора.

> «Сезонный ансамбль оптимизирован под зиму.»

Лучший RMSE Kt зимы (0.068) и худшая сумма Q зимы (0.25). Веса заданы вручную, как в приказе.

> «XGB с весом 3 зимой целенаправленно борется с недооценкой.»

Early stopping на val-годе, не на тесте. Зима Q̂/Qobs = 0.25, доля Q=0 = 0.875. Не помог.

> План тестирования: этап 2 (квантиль+ансамбль) → если не решает, этап 3 (hurdle) → этап 4 (XGB).

Этап 2 не решил. Этап 3 не решил. Этап 4 не решил. Tobit/бета/PyMC не ставили: оркул закрыл гипотезу о форме суточного Kt.

Что оркул запрещает считать «следующим шагом»: ещё одну суточную форму (tobit, бета, MixedLM, другой квантиль, другой XGB). Потолок уже измерен.

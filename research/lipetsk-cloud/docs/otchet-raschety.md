## 5. Почему sqlite давал 44 % и что с 9999

Импортёр: если НГО ≥ 9000 → null и **пара Q+НГО выкидывается**, даже если Q живой.

Стыковка на сетке станции 49 824 слотов (`scripts/lipetsk_join_gaps.py`, `csv/join_q_ngo_summary.json`):

| Класс | Слотов | Доля |
| --- | ---: | ---: |
| Q + валидное НГО (= sqlite) | 21 799 | 0.438 |
| НГО ≥ 9000 (все ровно 9999) | 27 320 | 0.548 |
| валидное НГО, в sqlite нет Q | 685 | 0.014 |
| нет метки аэропорта | 20 | 0.0004 |

Сырой Q vs prune (`scripts/lipetsk_q_vs_ngo.py`, `csv/q_raw_vs_ngo_summary.json`):

| | Сетка | С Q | Из них на 9999 | Доля DROP |
| --- | ---: | ---: | ---: | ---: |
| Всё | 49 824 | 48 206 | 26 361 | **0.547** |
| Лето MJJAS | 22 032 | 21 982 | 16 713 | **0.760** |
| Зима NDJ | 11 760 | 11 645 | 2 250 | 0.193 |

Все 21 799 строк sqlite сидят в минутках (sqlite без сырого Q = 0).

Днём 8–16 MSK средний Q, Вт/м² (`csv/ngo_9999_meaning.json`):

| Класс НГО | Q̄ | Доля Q>400 |
| --- | ---: | ---: |
| 9999 и N = 1…5 | **394** | 0.47 |
| 9999 и N = 0 | 310 | |
| база ≥ 1500 м | 314 | |
| база < 200 м | **37** | 0.007 |

9999 — ясно / облака выше потолка кеилиметра / NSC–CAVOK. Импортёр выкидывал как раз ясные часы. Поэтому C, Kd, GTI, Q считались с `hh_q_only.csv` / `hh_station.csv`, не с sqlite.

Исключение: **март 2024** — пиранометр почти молчал (2 полных дня из 31; ~96 получасов с Q). Это дыра радиации, не НГО. Сентябрь 2024: Q полный, sqlite пустой из‑за 97.5 % sentinel.

## 8. МГУ: подгонка Kd и с чем сличали

Код: `scripts/fit_diffuse_fraction.py`, готовые функции `scripts/msu_kd.py`. Обучение 1991–2012, пороги 2013–2018, **тест 2019–2021 и 2023–2024** (1792 суток, в обучение не входили). Split по годам, не shuffle. QC: F=0; GHI≥50 Дж/см²; 0≤DHI≤GHI; 0.03≤Kt≤0.85; H0≥1 МДж/м².

С чем сличали на тесте (суточный Kt, не часовой):

| Модель | RMSE Kd | RMSE Hd, МДж/м² | R² |
| --- | ---: | ---: | ---: |

| **МГУ-Рейндл** | **0.083** | **1.10** | **0.92** |

МГУ-Рейндл (после 0≤Kd≤1):

- Kt ≤ 0.23: Kd = 1.0349 − 0.1636 Kt − 0.0420 sin αn
- 0.23 < Kt ≤ 0.65: Kd = 1.4718 − 1.4351 Kt − 0.2363 sin αn

## 9. Этап 2. Hottel и размазка Href на получасовки

Hottel 1976, midlatitude:

$$ τb = a0 + a1 exp(−k / cos θz),\quad τd = 0.2710 − 0.2939 τb $$

r0,r1,rk: лето (IV–IX) 0.97 / 0.99 / 1.02; зима 1.03 / 1.01 / 1.00. Gcs = I0 (τb+τd).

$$ Gref,h = Gcs,h · Href,cs(m) / Σ_{h∈m} Gcs Δt $$

### 11.2. log(Kt) как в §11.4

Код: `scripts/lipetsk_actualize.py`. 972 суток (без 7 июльских без НГО). Kref = сумма **размазанного** Gref / H0. Hcloud: 9999 → 3000 м, иначе метры; log(H+10). Без uy/ud (ломают year-wise). Смещение логарифма: Kt̂ = exp(Xβ) · mean(exp resid) на train.

$$ log(Kt) = αm + β1 log(Kref) + β2 sin αn + β3 s + β4 log(H+10) $$

Полная выборка: β3(s)=1.52, β4=0.23, RMSE Kt=0.069, R²=0.88. Знак β4: выше кромка → выше Kt, физично.

| Тест | n | RMSE | R² | RMSE среднее |
| --- | ---: | ---: | ---: | ---: |
| 2025 | 347 | 0.074 | 0.86 | 0.201 |
| 2024 | 328 | 0.084 | 0.82 | 0.198 |
| 2023 | 297 | 0.066 | 0.88 | 0.194 |

### 11.3. Часовой log(kt)

Получасовка, I0>20, complete days. Метео только (для актуализации):

$$ log(kt) = αm + βref log(kref) + βs sh + βh log(H+10) + βz cosz $$

Year-wise RMSE ≈ 0.25, R² ≈ 0.60. sh — главный член. log(kref) и cosz коллинеарны, знак βref не интерпретировать.

AR(1) с **наблюдаемым** лагом: ρ ≈ 0.78–0.80, R² ≈ 0.79. Это nowcast по предыдущему Q, не прогноз из облачности. **В Qadj не входит.**

Отклонения от текста §11.4: шаг 30 мин, не час; нет сплайна сезона сверх месяцев; нет uy/ud.

## 14. Этап 7. ISO 9806: три Q

КПД:

$$ η = η0 Kτα − a1 (Tm−Ta)/G − a2 (Tm−Ta)²/G $$

Kτα_b = 1 − b0 (1/cosθ − 1); рассеянная и грунт — как 60°. η<0 → Q=0 (ниже Gcrit). Ta с логгера. Ветер не брали. Параметры — типичный остеклённый, не заводской коллектор.

Два знаменателя «ясного» Q, их нельзя смешивать:

| Имя | Облучённость в плоскости | Код | Год, кВт·ч/м² |
| --- | --- | --- | ---: |
| Qobs | измеренный IT (Эрбс+LJ) | оба скрипта | **416** |
| Qcs | Hottel beam+diffuse, без размазки СП | `lipetsk_collector.py` | **808** |
| Qref | Hottel × smear, Σмесяц = Href,cs | `lipetsk_actualize.py` | **1066** |
| Qadj | Gadj,h = Gref,h · Kt̂_oos / Kref_d | `lipetsk_actualize.py` | **386** |

Qadj — прогноз Kt с **чужого года**, профиль дня как у справочного ясного ряда. Это актуализация из плана, не пиранометр.

### 14.3. Семь зимних моделей (эксперимент, baseline не меняли)

# МГУ-Эрбс и МГУ-Рейндл

Суточный аналог формул Erbs (1982) и Reindl-2 (1990) по актинометрии WRDC **MOSCOW UNIV.**
Не замена часовому Эрбсу: у WRDC сутки, а не часы. Для поминутной/почасовой станции МГУ формулу нужно переподобрать.

Kt = H / H0,  Kd = Hd / H,  H0 по Duffie & Beckman, Gsc = 1367 Вт/м², φ = 55.70°.
Обучение 1991–2012, подбор порогов 2013–2018, проверка 2019–2021 и 2023–2024. Коэффициенты финально на train+val.

## МГУ-Эрбс

- Kt ≤ 0.23:  Kd = 1.0169 − 0.1571 Kt
- 0.23 < Kt ≤ 0.65:  Kd = 0.9556 + 1.0802 Kt − 4.8082 Kt² + 2.6467 Kt³
- Kt > 0.65:  Kd = 1.2851 − 1.4514 Kt
- затем 0 ≤ Kd ≤ 1

## МГУ-Рейндл

- α — высота Солнца в полдень; используем sin(α_noon)
- Kt ≤ 0.23:  Kd = 1.0349 − 0.1636 Kt − 0.0420 sin(α_noon)
- 0.23 < Kt ≤ 0.65:  Kd = 1.4718 − 1.4351 Kt − 0.2363 sin(α_noon)
- Kt > 0.65:  Kd = 1.4146 − 1.4475 Kt − 0.2004 sin(α_noon)
- затем 0 ≤ Kd ≤ 1

Прямая на горизонталь: `Bh = (1 − Kd) · H`.

Код: `scripts/msu_kd.py` — `msu_reindl(kt, sin_alpha_noon)`.

На отложенных годах 2019–2021 и 2023–2024 RMSE Kd = 0.083 (Erbs daily 0.093, Reindl-2 0.113).

## Научная задача
Цель — ранжировать по точности источники данных о суммарной солнечной радиации для востока России (стр. 2). Сравниваются среднемесячные оценки ERA5, CERES SYN1deg, «Научно-прикладного справочника по климату СССР» и трёх регрессионных моделей с наземными измерениями МЦРД (стр. 2).

Отдельная мотивация — оценить, можно ли использовать справочные данные, полученные 40–70 лет назад, в условиях климатических изменений (стр. 2). Исследование включает два этапа: (1) сравнение среднемесячных значений баз данных и справочника с МЦРД за 2006–2019 гг.; (2) сравнение месячных оценок регрессий М1–М3 с ERA5 и SYN1deg для отдельных лет с наиболее полными данными МЦРД (стр. 4).

## Исходные данные
- Регион: восток России — Иркутск, Чита, Оймякон, Якутск, Петропавловск-Камчатский, Южно-Сахалинск, Владивосток (стр. 2)
- Период: этап 1 — 2006–2019 гг. (стр. 4; в аннотации и выводах указано 2006–2020, стр. 1, 6); метеоданные rp5 — 2007–2019 гг. (стр. 3); справочник — 1937–1980 (Якутск) и с 1953–1957 до 1980 (остальные пункты) (табл. 1, стр. 2)
- Станции/спутник/реанализ/эксперимент: МЦРД (наземные измерения, суточные значения с 1964 г.; 16 станций на востоке России, с 2000 г. данные только по 7 пунктам) (стр. 2); ERA5 0,25°×0,25°, часовые (табл. 1, стр. 2); CERES SYN1deg 1°×1°, часовые (табл. 1, стр. 2); «Расписание погоды» (rp5.ru) — C, Cl, RH, Tmax, Tmin (стр. 3)
- Временной шаг: МЦРД — сутки; сравнение — месяц (среднемесячные/месячные суммы); метеоданные 8–24 срока в сутки → суточные значения программой Sun-MCA (стр. 3)
- Переменные: Hg (суммарная радиация на горизонталь), H0, общая облачность C, нижняя облачность Cl, RH, Tmax, Tmin, P, sin α (стр. 3)
- Размер выборки: 7 пунктов; для калибровки — по 3 года на пункт (стр. 3); число месячных пар не указано в тексте
- Пропуски и QC: в МЦРД пропуски от суток до нескольких лет (стр. 2); годы для калибровки выбраны по минимуму пропусков в rp5 и МЦРД (стр. 3); процедура QC и правило агрегации неполных месяцев не описаны

## Математический аппарат
- Модели: М1 — Hg = H0(a1 + a2C + a3C² + a4C³); М2 — Hg = H0(a5 + a6(Tmax − Tmin)^0,5 + a7RH + a8P); М3 (новая) — Hg = H0(a9 + a10C + a11Cl + a12RH + a13 sin α + a14Tmin + a15Tmax) (табл. 2, стр. 3)
- Формулы: среднемесячная суточная внеатмосферная радиация H0 = (24/π)·Isc·[1 + 0,033cos(360D/365)]·(cosφ cosδ sinωs + ωs sinφ sinδ), Isc = 1367 Вт/м² (ф-ла 1, стр. 3; в извлечённом тексте коэффициент выглядит как «0,33» — сверить с PDF); sin α = sinφ sinδ + cosφ cosδ cosω для полудня среднего дня месяца (ф-ла 2, стр. 3); MAE, MBE, RMSE (ф-лы 3–5, стр. 3)
- Индексы: Hg/H0 (по смыслу — месячный индекс ясности, в статье так не назван)
- Параметры: оценённые коэффициенты (стр. 4; знаки при членах в извлечённом тексте разорваны): М1 — 0,410717; 0,140414; 0,0272; 0,00133; М2 — 0,30943; 0,030307; 0,0011; 0,00019; М3 — 0,7; 0,03; 0,005; 0,0024; 0,1 (при sin α); 0,0006; 0,0006. Знаки требуют сверки по PDF.
- Способ оценки коэффициентов: регрессия по объединённому массиву из трёх лет каждого пункта, средствами Microsoft Excel (стр. 3); единые коэффициенты для всех 7 пунктов
- Учёт сезонности: через H0 и sin α для среднего дня месяца (стр. 3); отдельных сезонных моделей нет
- Учёт межгодовой изменчивости: нет (сравниваются многолетние средние или отдельные годы)
- Учёт облачности: общая C и нижняя Cl облачность из рядов rp5 (стр. 3); единицы облачности (баллы/доли) не указаны в тексте
- Учёт пространственной неоднородности: только через выбор пунктов с разными природно-климатическими условиями (стр. 2); способ извлечения значения ячейки ERA5/SYN1deg для пункта не описан
- Оценка неопределённости: только MAE/MBE/RMSE; доверительных интервалов нет

## Валидация
- Схема train/test: калибровка М1–М3 на трёх годах на пункт (стр. 3); проверка на «отдельных годах, выбранных по критерию полноты данных в базе МЦРД» (стр. 4) — из текста не следует, что тестовые годы отличаются от калибровочных
- Независимый период или станция: явно не указано; возможна оценка на обучающей выборке
- Метрики: MAE, MBE, RMSE, МДж/м²/мес (стр. 3–5)
- Главные численные результаты: этап 1, по всем пунктам (табл. 3, стр. 4): ERA5 MAE 18,1 / MBE 14,5 / RMSE 25; SYN1deg 22,3 / 3,8 / 29,8; справочник 17,3 / 4,9 / 22,5 МДж/м²/мес; справочник точнее в 4 из 7 пунктов (стр. 5). Этап 2 (табл. 4, стр. 5): М1 26,6 / −0,6 / 35,2; М2 30,9 / −6,3 / 40,1; М3 21,2 / −7,5 / 28,5; М3 лучше М1, М2 в 5 из 7 пунктов. Сравнение с базами (табл. 5, стр. 5): ERA5 21,0 / 10,3 / 28,4; SYN1deg 28,4 / 0,2 / 36,3; М3 — лучший источник в 4 из 7 пунктов. ERA5 преимущественно завышает (положительный MBE) (стр. 5).
- Проверка единиц: МДж/м²/мес — согласовано в табл. 3–5; Isc в Вт/м², H0 в формуле — суточная сумма (перевод единиц в тексте не показан)

## Главный результат
Среднемесячные значения суммарной радиации из справочника по климату СССР (1937/1953–1980) в 4 из 7 пунктов ближе к измерениям МЦРД 2006–2019 гг., чем ERA5 и SYN1deg, и в целом по всем пунктам имеют наименьшие MAE и RMSE (табл. 3, стр. 4–5). ERA5 точнее SYN1deg в 5 из 7 пунктов и в основном завышает радиацию (стр. 5–6). Новая регрессия М3 с нижней облачностью и высотой солнца по всем пунктам точнее М1 и М2 и лучше ERA5/SYN1deg в 4 из 7 пунктов (табл. 4–5, стр. 5).

## Ограничения
- Ограничение данных: 7 пунктов, все в Азиатской России; несоответствие периода (2006–2019 в тексте, 2006–2020 в аннотации и выводах); справочник [19] в списке литературы — выпуск 24 «Якутская АССР» (стр. 7), но используется для всех 7 пунктов, включая Иркутск и Владивосток — источник для них не ясен
- Ограничение модели: единые коэффициенты для всех пунктов; калибровка в Excel без перекрёстной проверки; тестовые годы могут совпадать с калибровочными; только месячный масштаб
- Ограничение переноса на Липецк: другой климат (резко континентальный/муссонный восток); коэффициенты М1–М3 переносить нельзя; переносима схема сравнения «справочник vs современные измерения МЦРД vs реанализ»

## Что можно использовать в нашем проекте
- Конкретный метод: сравнение справочных среднемесячных значений с современными наземными измерениями МЦРД и с ERA5 по MAE/MBE/RMSE (стр. 3–5)
- Формула или алгоритм: H0 по ф-ле (1) и sin α по ф-ле (2) (стр. 3); вид регрессии М3 с нижней облачностью (табл. 2, стр. 3)
- Какой раздел статьи поддерживает: статья A — обзор литературы и обсуждение («старые справочники остаются точнее реанализа»), выбор метрик; обоснование использования нижней облачности как предиктора
- Что нельзя переносить без проверки: коэффициенты М1–М3 (знаки не сверены, калибровка для востока России); вывод о превосходстве справочника — получен для всех погодных условий (средняя облачность), а не для безоблачного неба (СП 131)

## Анализ физических величин и методики
- Irradiance или irradiation; единицы (Вт/м², МДж/м², кВт·ч/м²): irradiation — месячные суммы/среднемесячные значения, МДж/м²/мес; Isc в Вт/м² (стр. 3)
- Поверхность (горизонтальная/наклонная/нормальная): горизонтальная (явно не сказано, следует из определения суммарной радиации и данных МЦРД)
- Компоненты (GHI/DHI/DNI/освещённость; среднее/сумма/мгновенное): только GHI (суммарная), месячные суммы
- Временной масштаб и совпадение с задачами проекта: месяц — совпадает с задачей сравнения справочных данных в статье A; для статьи B не подходит

Солнечное сияние не используется.

## Научная задача
Авторы автоматизируют расчёт нормативной глубины сезонного промерзания (оттаивания) грунтов по СП 22.13330 и приложению Г СП 25.13330 для изысканий на месторождениях в зоне многолетнемёрзлых грунтов (Красноярский край, ЯНАО) (стр. 2–5).

Ключевые проблемы, по авторам: выбор репрезентативной метеостанции (разночтения у субподрядчиков, замечания Главгосэкспертизы), необходимость обновления климатических данных нормативных документов по справкам метеостанций (п. 7.1.8 СП 47.13330.2016), трудоёмкий пересчёт единиц и теплофизических параметров (стр. 5–6). Модуль должен решить эти задачи (стр. 6).

- Период: не указано в тексте (данные СП 131.13330.2012 + справки станций «за последние годы исследований», стр. 7)

- Временной шаг: среднемесячная и среднегодовая температура воздуха (стр. 7)
- Переменные: температура воздуха; снежный покров (высота, плотность), температура грунта — вводятся по натурным данным (стр. 8); теплофизические свойства грунта
- Размер выборки: не применимо (ПО); применено в >20 технических отчётах (стр. 11)
- Пропуски и QC: не описаны; контроль ввода через конвертер единиц (стр. 8) и прозрачность единой базы данных станций (стр. 7)

## Математический аппарат
- Модели: задача Стефана в постановке приложения Г СП 25.13330 (линейное распределение температуры в мёрзлой/талой зоне, постоянная температура поверхности, теплоёмкость = 0) (стр. 6); для глубины ≤ 2,5 м — зависимость нормативной глубины от суммы абсолютных значений среднемесячных отрицательных температур по СП 22.13330 (стр. 5; формула в статье не приведена)
- Формулы: в статье не выписаны; перечислены параметры п. Г.8 СП 25.13330: Tf,m, tf,m, Tth,m, tth,m, Tth,c, tth,c; снег ds, ρs, λs, Rs (стр. 8; индексы в извлечённом тексте разорваны)
- Индексы: не применимо
- Параметры: нормативная глубина — среднее ежегодных максимальных глубин за период наблюдений не менее 10 лет (стр. 4)
- Способ оценки коэффициентов: теплопроводность грунта — интерполяция табл. Б.8 СП 25.13330 на нерегулярной сетке методом радиальных базисных функций (RBF) в 2D с табличными значениями как опорными точками; теплоёмкость — по формулам п. Б.6, Б.7, Б.9 (стр. 10); численная библиотека ALGLIB (стр. 7)
- Учёт сезонности: через периоды отрицательных/положительных температур (стр. 8)
- Учёт межгодовой изменчивости: нет
- Учёт облачности: нет
- Учёт пространственной неоднородности: только выбор ближайшей станции по геодезическому расстоянию (алгоритм Винсента) либо ручной выбор «репрезентативной» станции (стр. 8)
- Оценка неопределённости: нет

## Главный результат
В АО «ТомскНИПИнефть» разработан модуль (Excel VSTO + надстройка на C# 6.0/.NET 4.6.1, ALGLIB, LiteDB), автоматизирующий расчёт нормативных глубин промерзания (оттаивания) по СП 25.13330 и выбор метеостанции (стр. 6–8). Климатические данные хранятся на едином ГИС-сервере (СП 131.13330.2012, частично обновлены по справкам станций) и обновляются через WFS (OGC) уполномоченным пользователем (стр. 7). Ближайшая станция определяется по координатам объекта по геодезическим линиям (алгоритм Винсента); табличные теплофизические параметры интерполируются RBF (стр. 8, 10). Валидации результатов расчёта в статье нет.

## Ограничения
- Ограничение данных: справочные температуры СП 131.13330.2012 с частичным обновлением по справкам — без описания процедуры, периода и контроля качества обновлений.
- Ограничение модели: выбор станции только по расстоянию (без учёта высоты, рельефа, полноты рядов); точность RBF-интерполяции табличных значений не оценена; сравнения расчётных глубин с наблюдениями в скважинах нет.
- Ограничение переноса на Липецк: прямого нет (мерзлота, температура); переносимы лишь программные решения.

## Что можно использовать в нашем проекте
- Конкретный метод: архитектура хранения справочных климатических данных с версионированием/обновлением по фактическим данным станций; автоматический выбор ближайшей станции по геодезическому расстоянию (Винсент); RBF-интерполяция по нерегулярной сетке табличных значений.
- Формула или алгоритм: алгоритм Винсента для расстояний; RBF (ALGLIB) — как вариант пространственной интерполяции справочных радиационных значений в C#-модуле (с обязательной кросс-валидацией, которой у авторов нет).
- Какой раздел статьи поддерживает: статья A — Введение (практика: экспертиза требует обновлять климатические данные нормативных документов, стр. 5) и Методы/описание модуля (аналог программной реализации).
- Что нельзя переносить без проверки: выбор «ближайшей станции» как достаточного критерия репрезентативности; RBF без оценки ошибки; утверждение, что модуль «помогает в корректном выборе метеостанций», — не подтверждено проверкой.

## Точные цитируемые фрагменты
- Страница/раздел: стр. 5, «Методики расчета»
- Фрагмент или точный пересказ: при прохождении Главгосэкспертизы «поступают замечания по выбору метеостанции или необходимости обновления климатических данных нормативных документов путем запроса справок с метеостанций».
- Почему важен: практическое подтверждение того, что таблицы СП 131 считаются устаревающими и требуют актуализации по данным станций.

- Страница/раздел: стр. 7, «Результаты»
- Фрагмент или точный пересказ: «На сервере данных содержится информация о средней ежемесячной и годовой температуре воздуха по данным метеостанций согласно СП 131.13330.2012, а также по некоторым станциям температура обновлена согласно полученным справкам с метеостанций за последние годы исследований.»
- Почему важен: прецедент программного объединения справочных данных СП с обновлениями по фактическим наблюдениям.

- Страница/раздел: стр. 8, «Результаты»
- Фрагмент или точный пересказ: при задании координат объекта ближайшая станция выбирается автоматически; «Для сортировки и выбора станции используется расчёт геодезических линий по алгоритму Винсента.»
- Почему важен: конкретный алгоритм для C#-модуля (поиск станций/узлов по расстоянию).

- Страница/раздел: стр. 10, «Результаты»
- Фрагмент или точный пересказ: значения теплопроводности по табл. Б.8 СП 25.13330 «определяются с использованием интерполяции на нерегулярной сетке по методу радиальных базисных функций (RBF) для двумерного пространства с применением табличных значений как опорных точек».
- Почему важен: пример интерполяции нормативных табличных данных RBF — сопоставимо с интерполяцией справочных таблиц СП 131 в нашем модуле.

## Анализ физических величин и методики
- Irradiance или irradiation; единицы (Вт/м², МДж/м², кВт·ч/м²): не применимо
- Поверхность (горизонтальная/наклонная/нормальная): не применимо (горизонтальная площадка без снега — только в определении нормативной глубины, стр. 4)
- Компоненты (GHI/DHI/DNI/освещённость; среднее/сумма/мгновенное): не применимо
- Временной масштаб и совпадение с задачами проекта: месячные/годовые температуры, сезонные периоды; с задачами проекта не совпадает, кроме уровня «справочные таблицы СП»
- Солнечная геометрия (зенитный угол, часовой угол, H0/I0, Cooper/Spencer/Duffie–Beckman, транспозиция): не применимо
- Облачность (общая, нижняя граница, оптическая толщина, cloud mask, солнечное сияние, косвенные предикторы; допущения, которые нельзя переносить): не применимо
- Пространственная интерполяция (число станций, расстояния, метод, кросс-валидация, ошибки; карта без проверки — не доказательство): пространственной интерполяции климатических данных нет — только ближайшая станция (Винсент); RBF применяется к таблицам свойств грунта, не к пространству; кросс-валидации нет
- Временная структура (повтор календарных дней, сезонная/годовая/суточная компоненты, автокорреляция, независимый тестовый год, моделирование пиков внутри дня): не применимо
- Коллектор и тепловая модель (тип, площадь, η0/a1/a2, IAM, температуры, расход, наклон/азимут, транспозиция, критерий насоса, Gcrit, единицы теплоты; «типовые» параметры ≠ валидация изделия): не применимо (тепловая модель — задача Стефана для грунта)

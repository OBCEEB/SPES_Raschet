## МГУ-Эрбс и МГУ-Рейндл

По суткам WRDC МГУ подобраны аналоги Erbs (1982) и Reindl-2 (1990). Это **суточный** `Kd(Kt)`, не часовой: у WRDC дневные суммы. Для поминутной станции сначала сжать день в `H`, либо ждать часовой ряд GHI+DHI.

Проверка на 2019–2021 и 2023–2024 (1792 суток, в обучение не входили):

| Модель | RMSE Kd | RMSE DHI, МДж/м² | R² |
| --- | ---: | ---: | ---: |
| Erbs daily | 0.093 | 1.21 | 0.89 |
| Reindl-2 (часовой, на суточный Kt) | 0.113 | 1.80 | 0.84 |
| **МГУ-Рейндл** | **0.083** | **1.10** | **0.92** |
| МГУ-Эрбс (только Kt) | 0.092 | 1.34 | 0.90 |

МГУ-Эрбс почти не лучше суточного Эрбса. Выигрыш даёт высота Солнца, особенно летом (июнь: RMSE 0.082 против 0.102 у Erbs daily). Коэффициент при `sin α` отрицательный: при том же Kt летом в Москве меньше рассеянной доли, чем предсказывают американские формулы.

**МГУ-Рейндл** (α — высота в полдень, затем 0 ≤ Kd ≤ 1):

- Kt ≤ 0.23: Kd = 1.0349 − 0.1636 Kt − 0.0420 sin α
- 0.23 < Kt ≤ 0.65: Kd = 1.4718 − 1.4351 Kt − 0.2363 sin α
- Kt > 0.65: Kd = 1.4146 − 1.4475 Kt − 0.2004 sin α

Прямая на горизонталь: `Bh = (1 − Kd) · H`. Код: `scripts/msu_kd.py`. Подгонка: `python3 scripts/fit_diffuse_fraction.py`.

СП 13.1 — ясное небо. Для Липецка отдельно: интерполяция Href,cs (C#) и коэффициент облачности `C = Hobs / Href,cs`, это не Kt. S и нижняя граница облаков не заменяют DHI. Цепочка: рабочий материал §11.

**Важно:** СП 131 даёт радиацию при **ясном небе**. Для энергоустановок нужны суммы при **реальной облачности**. Для Москвы это примерно 1045 кВт·ч/м²·год (NASA POWER) против ~1600 кВт·ч/м²·год по СП 131 на 56° с.ш.

Единицы: **1 кВт·ч/м² = 3.6 МДж/м²**.

## Какой формат нужен для расчёта солнечных коллекторов

Горизонтальный GHI — исходник, не конечный вход. Коллектор стоит под углом, оптика разная для прямой и рассеянной, КПД зависит от `(T − T_нар) / G`. Поэтому в расчёт идут **прямая и рассеянная по отдельности**, затем перевод в **плоскость коллектора**, плюс **температура воздуха**.

| Методика | Что просить у климатологии | Шаг | Единицы | Плоскость |
| --- | --- | --- | --- | --- |
| [ВСН 52-86](https://www.vashdom.ru/vsn/52-86/), прил. 3 | Прямая `I_s` и рассеянная `I_d` **на горизонталь** + `t_e` | Час светового дня (для дублёра юг: 8–17 ч) | Вт/м² и °C | Горизонталь → наклон: `q = P_s I_s + P_d I_d`, `P_d = cos²(β/2)` |
| Инженерный месячный (Liu–Jordan / f-chart) | Среднесуточные `H` (GHI), лучше сразу `B_h` и `D_h`; если только `H` — расщепить через `K_T = H/H_0` | Месяц | МДж/м²·сут или кВт·ч/м²·сут | Наклон: `I_c = B_h R_b + D_h (1+cos β)/2 + H ρ (1−cos β)/2` |
| ISO 9806 / динамика (TRNSYS, Polysun) | DNI + DHI (+ GHI), `T`, ветер для незастеклённых | Час, TMY/TRY | Вт/м² | Плоскость коллектора; IAM отдельно для прямой и рассеянной |
| ISO 9459-2 | Суточная сумма облучения + `T` + `T` холодной воды | Сутки | МДж/м²·сут | Обычно плоскость коллектора |
| ISO 9459-5 | Часовой метеоряд (test reference year) | Час | Вт/м² | Плоскость коллектора |
| Концентраторы (CPC, лотки) | **DNI**, не GHI | Час | Вт/м² | Нормаль к лучу |

Минимальный набор, который стоит качать:

- `ALLSKY_SFC_SW_DWN` — GHI (сумма на горизонталь)
- `ALLSKY_SFC_SW_DIFF` — DHI (рассеянная на горизонталь)
- `ALLSKY_SFC_SW_DNI` — DNI (прямая по нормали); прямая на горизонталь `B_h = GHI − DHI`
- `T2M` — температура воздуха

NASA POWER отдаёт это по lat/lon почасово и климатологией: [документация потоков](https://power.larc.nasa.gov/docs/methodology/energy-fluxes/), [наклонные плоскости GTI](https://power.larc.nasa.gov/docs/methodology/energy-fluxes/tilted-surfaces/).

ВСН 52-86 прямо говорит брать часовые прямую и рассеянную и `t_e` из *Справочника по климату СССР* (1966). Месячная сумма только GHI на горизонталь годится для грубой оценки или как `H` для расщепления Liu–Jordan, но не как единственный вход в тепловой баланс коллектора.

## Как запросить точку по координатам

1. Открыть [NASA POWER DAV](https://power.larc.nasa.gov/data-access-viewer/), community **RE**, параметр **ALLSKY_SFC_SW_DWN**, режим climatology или monthly.
2. Либо подставить lon/lat в URL API выше.
3. Для карты без API: клик на [globalsolaratlas.info](https://globalsolaratlas.info/map) — поле GHI.

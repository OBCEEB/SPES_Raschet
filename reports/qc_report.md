### Flag definitions

- `qc_missing_row` — no observation joined for the half-hour slot
- `qc_missing_*` — named variable is null
- `qc_negative_q` — `radiation_wm2` (`q_mjm2`) < 0
- `qc_night_suspect` — `radiation_wm2` > 0 while approximate solar elevation < `quality_control.min_solar_elevation_deg` (5°)
- `qc_ngo_censored` — residual `ngo_m` ≥ 9000 (importer normally nulls these)
- `qc_flatline_q` — identical non-null Q lasting ≥ 6 h

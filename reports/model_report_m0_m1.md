## Clear-sky model

- **Model:** Ineichen–Perez (2002) horizontal GHI (`G_cs`).
- **pvlib:** preferred, but not installable offline/online here (PyPI TLS/proxy failure); formulas match the usual `pvlib.clearsky.ineichen` implementation.
- **Linke turbidity:** 3.0 (config; site TL UNKNOWN).
- **Daytime:** solar elevation ≥ 5°; `k_obs = G_obs/G_cs` only when `G_cs` ≥ 5.0 W/m²; night → `G_cs=0`, `k_obs` null.

## Handbook baseline `B_ref`

- C# UI not callable without WinForms; **Python reimplements** `MathTools.Interpolate` + table load.
- Horizontal series: interpolate `DailyTotalData.csv` (Вт·ч/м² per code comments) at site lat, then distribute across hours with handbook `SunPosition_Altitude` weights `max(sin(alt),0)`.
- Conversion: hourly Wh/m² over 1 h ⇒ mean W/m² of equal magnitude; half-hours inherit that mean.
- **Limits:** climatological (no month/DOY in tables); Table 1 is façade-only — not used as horizontal GHI. UI labels DailyTotal as МДж/м² but analysis follows code comments (Вт·ч/м²). Interpolated daily total at site: **328.9322955** W·h/m².
- Method tag: `daily_total_x_handbook_sin_altitude`.
